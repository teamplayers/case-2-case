## Open-source use (free)

You may use, copy, modify, and distribute case2case at no charge if you comply with AGPL-3.0. That includes use by commercial companies, as long as the resulting work stays open source.

In practice, that means:

1. **Source availability** — If you distribute the software (or a modified version), you must provide corresponding source code to recipients under AGPL-3.0.
2. **Network use (SaaS)** — If you run a modified version as a service over a network (for example, a web app or API), users interacting with it remotely must be able to obtain the source code for the version they use.
3. **Same license on derivatives** — Works based on case2case must remain under a license compatible with AGPL-3.0.

Compatible licenses include AGPL-3.0 and GPL-3.0. When in doubt, release your derivative under AGPL-3.0.

## Closed-source use (permission required)

AGPL-3.0 does **not** permit using case2case in a proprietary or closed-source product without complying with the copyleft obligations above.

If you need any of the following, you must obtain a separate [commercial license](commercial-license.md):

- Keep your changes or integration closed source
- Run a private SaaS or internal deployment without offering source to users
- Distribute a product that includes case2case without open-sourcing the combined work

Contact us with your **use case** (who will use it, how it is deployed, and what stays closed). We grant commercial licenses on a case-by-case basis.
